# 学霸模式(应用白名单)设计

> 参考文档:番茄Todo「应用白名单」功能(学霸模式核心机制)详细说明,2026-09-14 落地。

## 背景

专注锁定此前仅实现应用内行为(隐藏导航/拦截返回/常亮/放弃确认,见 2026-09-09-focus-lock-design.md),明确不做系统级拦截。本次按番茄Todo学霸模式完整机制补齐:应用白名单、标准/严格两级锁定、紧急退出密码与非正常退出记录。

## 核心规则

1. **触发时机**:学霸模式开启后不立即生效;启动番茄钟专注计时(番茄钟/正计时/倒计时)时自动激活,计时结束(完成/中止/紧急退出)随前台服务销毁自动解除。
2. **标准模式**:轮询识别前台应用,白名单内放行(词典/网课/刷题等工具类),其余应用拉回研钟并提示「应用已禁用 · 专注期间仅可使用白名单应用」。
3. **严格模式**:专注期间完全锁定在研钟专注界面——无法退出研钟、无法切换到任何应用(含白名单)、无暂停/放弃入口;仅计时结束或 6 位紧急退出密码可解除。
4. **紧急退出**:PIN 仅存 SHA-256 哈希;验证通过强制结束专注,落库 `abandonReason="严格模式紧急退出"`、`valid=false`,统计页中断分析自动归类「非正常退出」。忘记密码只能等待计时结束(防逃逸设计)。
5. **场景化策略**:按科目定制白名单(`subjectId → 包名集`),启动该科目任务(或专注中补选科目)时切换为定制集;未定制科目使用全局白名单。

## 权限边界与实现方式

普通应用无法真正禁止其他应用启动(系统级 Screen Time Guard Kit 不开放),采用 Android 权限边界内的最大强度方案:

- **前台识别**:`UsageStatsManager.queryEvents` 轮询(1s)最近前台应用,依赖「使用情况访问」特殊权限(PACKAGE_USAGE_STATS),设置页引导授权;未授权时标准模式不拦截(开钟 Toast 提示)。
- **拉回**:检测到违规前台应用时由 FocusService(前台服务,具备后台启动 Activity 豁免)`startActivity` 拉回研钟,限频 900ms 防风暴,Toast 限频 5s。
- **严格模式防逃逸**:`MainActivity.onStop` 即时上报拉回(不依赖轮询,无权限也生效)+ 轮询兜底;Home/划后台/通知栏跳转均被拉回。
- **通知静默**:其他应用通知的收纳需 NotificationListenerService 单独授权,本期不做。

## 状态与数据

- 设置全部存 DataStore(`super_mode_on/super_mode_strict/emergency_pin_hash/guard_whitelist/guard_subject_whitelist`),无 Room schema 变更。
- `FocusService.guardActive/guardStrictNow` 为内存快照,供 Activity 生命周期即时查询;进程重启由 `restoreIfNeeded` 重建拦截。
- 拦截状态由引擎唯一事实来源 `TimerState.isRunning` 决定,暂停/休息阶段保持锁定,符合学霸模式语义。

## 界面

- **我的 → 学霸模式**(新路由 `supermode`):总开关 → 严格等级卡 → 拦截权限引导 → 紧急退出密码(严格) → 白名单管理(标准,入口 `apppicker/{subjectId}`,subjectId=-1 为全局)。
- **应用选择器**:启动器应用列表(排除自身),图标+名称+包名+复选框,搜索+全选/清空批量操作。
- **专注运行态**:徽章行显示「🔒 严格锁定中」或「🔓 白名单内 N 个应用可用」;严格模式隐藏暂停/放弃/结束,提供「紧急退出」入口 → 6 位 PIN 对话框(错误提示重试)。

## 验证

- 编译:`:app:compileDebugKotlin`。
- 交互:开钟激活/结束解除;标准模式白名单放行与非白名单拉回;严格模式 onStop 拉回与 PIN 退出;紧急退出后统计页中断分析出现「严格模式紧急退出」;科目定制策略随任务切换生效。
