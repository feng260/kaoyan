# 四页 UI 全面优化设计（今日 / 专注 / 统计 / 我的）

日期：2026-09-08
前置：计划页五阶段总览卡已重做（纵向进度轨道 + 三态徽标 + 当前阶段强调块 + 弱底色块 + 彩点胶囊）。
目标：其余四页对齐计划页视觉语言，统一设计规范，补齐朴素区块。不动业务逻辑、ViewModel、数据库。

## 一、跨页设计规范

| 维度 | 规则 |
|---|---|
| 圆角 | 主体卡片 `MaterialTheme.shapes.large`；卡片内小容器 `shapes.medium`；标签一律 999dp 胶囊 |
| 间距 | 页面横向边距 16dp；卡片内边距 16dp；列表项间距统一 12dp |
| 颜色 | `SuccessGreen`、科目标签色统一引用主题/`tagColor`；Color.kt 补齐缺失常量（默认标签色 0xFF64748B、琥珀内容色 0xFF5C4400、红内容色 0xFF5A0F0F） |
| 视觉语言 | 状态胶囊、弱底色块（container 色 0.3~0.45 透明度）、8dp 彩点全面铺开 |

## 二、各页改动

### 今日页
- PhaseStrip：阶段名 + 第 X/Y 天 + 按天数比例五段进度条（当前段主色、过去降饱和、未开始弱化），参考计划页 PhaseTimeline。
- QuickStartBar：标准 Surface 卡（tonalElevation=1），「开新番茄」主色胶囊按钮，最近任务 chips 化。
- TodayRhythmCard：色点 8dp、时段列对齐（同计划页 BlockRow）。
- EmptyTaskHint：图标 + 引导文案层级。
- 弹窗：输入区圆角与间距微调，保守改动。

### 专注页（仅空闲态）
- 方案选择：FilterChip → 方案卡片，选中 primaryContainer 弱底色强调块 + 对勾，未选中弱化；时长胶囊（如「25 + 5」）。
- 开关区：行加弱底色圆角容器。
- 任务行：色点 8dp、开始按钮主色胶囊。
- 运行态不动。

### 统计页
- 折线图：Y 轴刻度值、X 轴隔天日期、折线下渐变面积。
- 柱状图：0/6/12/18/24 小时标签 + 基线，黄金时段结论胶囊化。
- 环形图：图例加百分比，外圈 subtle 轨道。
- KPI 行：数值/单位分层排版；周报卡达成徽章胶囊化。

### 我的页
- 番茄方案列表：选中高亮块（同专注页方案卡，两页统一风格）。
- 开关行、科目管理行：弱底色圆角行容器，科目色点放大。
- 备份导入说明：NoteText 弱底色块。
- 品牌 Banner 不动。

## 三、实施与验证
