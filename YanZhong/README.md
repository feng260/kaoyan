# 研钟 YanZhong

考研学习效率工具 · 安卓原生 App · M1 版本(1.0.0-m1)

> 学什么用扇贝,怎么学、学得怎么样用研钟。
> 本 App 按《468 天考研全程作战计划》个人定制:五阶段骨架、六套日模板、四科全程规划、启动四周、资料清单、十条军规全部内置。

## 定位

研钟是「扇贝考研」的补充配套工具,只做三件事:

1. **倒计时锚点** — 多节点倒计时(初试/单科/复试/报名/模考),置顶展示、逐秒刷新、预警配色
2. **番茄钟与任务管控** — 番茄钟状态机、今日待办、科目分组、快速开钟补选科目
3. **多维度统计复盘** — 净专注时长、科目占比、趋势折线、黄金时段、连续打卡

离线优先 · 本地数据 · 零广告 · 零社区 · 零资讯流。

## 技术架构

- **语言/UI**:Kotlin 2.0 + Jetpack Compose(Material 3)
- **架构**:MVVM + UDF(ViewModel / StateFlow / 单一数据源)
- **存储**:Room(SQLite,离线优先)+ DataStore(偏好与计时现场)
- **后台**:前台服务保活计时(基于 `SystemClock.elapsedRealtime()` 单调时钟,息屏、切后台、改系统时间均不影响精度;进程被杀后可恢复现场)
- **序列化**:kotlinx.serialization(数据导出)
- **最低支持**:Android 10(API 29)· 目标 API 34

## 构建

环境要求:

- Android Studio Koala(2024.1.1)+ 或仅命令行
- JDK 17+(已含 Gradle Wrapper,首次构建自动下载 Gradle 8.9)
- Android SDK Platform 34

```bash

gradlew.bat assembleDebug        # Windows

gradlew.bat installDebug
```

或在 Android Studio 中打开 `YanZhong/` 目录,等待 Gradle Sync 完成后直接 Run。

## 导入考研学习计划

项目根目录提供 `yanzhong-plan-import.json`(与内置计划包同源,基于 468 天考研全程作战计划生成):

- **内容**:13 个倒计时节点(五阶段收官、政治入场、预报名、正式报名、网上确认、准考证、成绩、复试)+ 30 个任务(12 个每日/每周周期模板 + 18 个全程里程碑)
- **用法**:把 JSON 文件传到手机(微信文件传输助手 / USB / 网盘均可)→ 打开研钟 → 我的页 →「备份与导入」→ 点「导入计划 JSON」→ 选择该文件(内置包已随首启自动导入,手动导入一般无需)
- **合并规则**:科目按名字自动合并到预置四科;同名节点/任务自动跳过,重复导入同一文件不会产生重复数据
- 导入后,周期任务会按星期几自动出现在每日「今日待办」;计划页「本周」按天展开每日/每周任务;里程碑显示在「本周」底部的近期里程碑卡,临近截止自动进入对应周

## 设计要点(ADR)

- **计时精度**:不累加计时,而是「记录起点 + 每秒渲染差值」,基于单调时钟;进程被杀后从 DataStore 恢复现场(ADR-001)
- **暂停上限**:累计暂停超过 5 分钟自动恢复,防止无限暂停刷记录
- **放弃防误触**:专注页放弃需长按 1.5 秒,按住时按钮渐变红
- **重复任务**:模板常驻、完成时生成当日实例,模板不消耗
- **数据自有**:全量数据(科目/节点/任务/专注记录)一键导出 JSON,SAF 选择位置,不申请任何存储权限
